Finding broken links is easy. Knowing which ones matter, and fixing them in bulk, is the hard part.

In short

  • Check the HTTP status of every link: 404 and 410 mean gone, 5xx and timeouts need a second look.
  • Big platforms often block automated checks, so a failure from them is not proof of a broken link.
  • Fix links in menus, headers and footers first. One edit repairs every page.

Ways to find broken links

  • By hand. Click through important pages. Fine for ten pages, hopeless for hundreds.
  • Search console reports. Google Search Console lists pages it could not find, but only those it tried to crawl.
  • A crawler or link checker. It reads every page, collects the links, and requests each one. A broken link checker for documentation also shows where each link sits.

Real breakage and false alarms

  • 404 and 410: the page is gone. Almost always real.
  • 500 errors and timeouts: may be momentary. Check again before acting.
  • 403, 429, 999: usually the site refusing an automated request. Google, Facebook, LinkedIn and similar sites do this for working pages.
  • Links to /wp-admin, edit pages, preview URLs, staging or localhost: not broken for you because you are signed in, but unreachable for every visitor.

Fix them in the right order

  1. Menu, header and footer links, which repeat on every page.
  2. Links inside popular articles.
  3. Links to pages you renamed or moved: add a redirect instead of editing every link.
  4. External links that moved: update them or remove them.

Keep them fixed

Links break again every time a page moves. Rescan on a schedule and fix the new ones as they appear. Scan your site for broken links now.
